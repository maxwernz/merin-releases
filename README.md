# Merin

Downloads von Merin, einem lokalen Forschungsfeed für macOS (Apple Silicon). Dieses Repository enthält nur Builds, keinen Quellcode.

Unter [Releases](https://github.com/maxwernz/merin-releases/releases) das neueste `.dmg` laden, Merin in den Programme-Ordner ziehen. Beim ersten Öffnen: Rechtsklick → Öffnen (die App ist nicht notarisiert). Danach aktualisiert sich Merin selbst.
